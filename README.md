# 📇 NexGen Contact Manager

A modern and user-friendly **web-based contact management application** that allows users to efficiently store, view, update, and delete contact information.  
Built to demonstrate real-world **CRUD operations**, clean UI design, and structured backend integration.

---

## 🌟 Overview

**NexGen Contact Manager** is designed to simplify contact organization for personal or professional use.  
The application provides an intuitive interface and robust functionality for managing contact data efficiently.

This project showcases practical web development skills, including frontend design, backend logic, and seamless data handling.

---

## ✨ Features

- ➕ Add new contacts
- 👁 View contact details
- ✏️ Edit existing contacts
- 🗑 Delete contacts
- 📋 Organized contact listing
- 🎨 Clean and responsive user interface
- 🔄 Full CRUD functionality

## 🚀 Getting Started

### Prerequisites

- Java JDK
- Web browser
- IDE (optional)

### Run the Project

1. Clone the repository:
```git clone https://github.com/AQUIB7050/NexGen-Contact-Manager.git```
2. Open the project in your IDE.
3. Run the server and open the application in your browser.
